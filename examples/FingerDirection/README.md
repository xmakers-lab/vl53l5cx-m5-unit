# FingerDirection

VL53L5CX の 8x8 距離マップから、センサー正面にかざした人差し指がさしている方向（上下左右・斜め4方向の計8方向）を認識するサンプルです。[RockPaperScissors](../RockPaperScissors) のポーズ判定をベースに、指の指し示す向きの判定を追加しています。

## 仕組み

1. 各フレームで、64ゾーン全体から最も近い有効な距離（`nearest`）を探す。手の検出範囲は固定値ではなく、そこから `NEAR_WINDOW_MM`（既定: 5cm）以内という動的な窓にする。こうすることで、手を20cm付近に構えても30cm付近に構えても、その都度いちばん近いところに窓が追従する。
2. ただし窓の中心（`nearest + NEAR_WINDOW_MM/2`）が `WINDOW_CENTER_MIN_MM`〜`WINDOW_CENTER_MAX_MM`（既定: 12〜30cm）の範囲外なら、その場でいちばん近いものが壁など手以外の可能性が高いとみなしてそのフレームは検出なし扱いにする。
3. 動的な窓の範囲に入っているゾーンを「手（指）がある」とみなし、`MIN_VALID_ZONES` 個以上あれば検出したと判断して、それらのゾーンの重心（グリッド座標）を計算する。指を含む手は片側に偏った細長い塊になるため、重心は指の付け根側（手のひら寄り）に寄る。
4. 重心から最も離れたゾーンを指先（tip）とみなし、重心→指先のベクトルを求める。このベクトルの向きが指のさす方向になる。
5. ベクトルの長さが `MIN_POINT_VECTOR_CELLS` 未満（重心と指先がほぼ同じ位置＝細長い塊になっていない）の場合はノイズとして無視する。
6. ベクトルの角度を8方向（上/右上/右/右下/下/左下/左/左上）に分類し、`STABLE_FRAMES_REQUIRED` フレーム連続で同じ方向が検出されたら確定として画面上部に表示する。
7. 手が `MISSING_FRAMES_TO_END` 回連続で検出されなくなったら候補をリセットする。

ヒートマップ上には重心から指先へ向かう矢印を重ねて表示し、判定根拠を視覚的に確認できるようにしている。

## しきい値の調整

`src/main.cpp` 冒頭の定数で挙動を調整できます。

| 定数 | 説明 |
| ---- | ---- |
| `NEAR_WINDOW_MM` | 最も近い距離から何mm以内を「手」の窓とするか |
| `WINDOW_CENTER_MIN_MM` / `WINDOW_CENTER_MAX_MM` | 動的な窓の中心がこの範囲外なら検出なし扱いにする大枠のフィルタ |
| `MIN_VALID_ZONES` | 検出と判定するために必要な有効ゾーン数 |
| `MIN_POINT_VECTOR_CELLS` | 重心→指先ベクトルを方向判定に採用する最小長さ（グリッドセル単位） |
| `STABLE_FRAMES_REQUIRED` | 方向を確定させるために必要な連続一致フレーム数 |
| `DIRECTION_DISPLAY_MS` | 判定結果を画面に表示しておく時間 |
| `MISSING_FRAMES_TO_END` | 候補をリセットするまでの連続未検出フレーム数 |

## 使い方

センサーの正面 12〜30cm の位置で人差し指を伸ばし、指したい方向（上下左右・斜め）へ向けます。しばらく同じ向きを保つと、画面上部に判定結果（上/右上/右/右下/下/左下/左/左上）が表示されます。
