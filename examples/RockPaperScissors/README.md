# RockPaperScissors

VL53L5CX の 8x8 距離マップから手の形（グー・チョキ・パー）を認識するサンプルです。[HeatmapDisplay](../HeatmapDisplay) のヒートマップ表示をベースに、手の輪郭の形状（面積・縦横比）によるポーズ判定を追加しています。

## 仕組み

1. 各フレームで、距離が `HAND_MIN_MM`〜`HAND_MAX_MM`（既定: 200〜400mm）の範囲にあるゾーンを「手」とみなし、そのゾーン数（面積）とバウンディングボックス（幅・高さ）を求める。
2. 該当ゾーンが `MIN_VALID_ZONES` 個未満なら、手なしと判定する。
3. バウンディングボックスの長辺/短辺比が `ASPECT_ELONGATED_MIN`（既定: 1.7）以上なら、指が伸びた細長い形＝チョキと判定する。
4. 細長くない場合は、面積が `AREA_ROCK_PAPER_SPLIT`（既定: 22ゾーン）以上ならパー（開いた手）、未満ならグー（握った拳）と判定する。8x8の解像度では個々の指は判別できないため、面積と縦横比のみによる粗い判定になっている。
5. `STABLE_FRAMES_REQUIRED` フレーム連続で同じポーズが検出されたら確定として画面上部に日本語（グー/チョキ/パー）で表示する。
6. 手が `MISSING_FRAMES_TO_END` 回連続で検出されなくなったら候補をリセットする。

画面下部には判定に使った面積・幅・高さの値をデバッグ表示している。誤判定する場合は、この値を見ながら `ASPECT_ELONGATED_MIN` / `AREA_ROCK_PAPER_SPLIT` を調整する。

## しきい値の調整

`src/main.cpp` 冒頭の定数で挙動を調整できます。

| 定数 | 説明 |
| ---- | ---- |
| `HAND_MIN_MM` / `HAND_MAX_MM` | 手として検出する距離範囲 |
| `MIN_VALID_ZONES` | 手ありと判定するために必要な有効ゾーン数 |
| `ASPECT_ELONGATED_MIN` | チョキ（細長い形）と判定する長辺/短辺比のしきい値 |
| `AREA_ROCK_PAPER_SPLIT` | グーとパーを分ける面積（ゾーン数）のしきい値 |
| `STABLE_FRAMES_REQUIRED` | ポーズを確定させるために必要な連続一致フレーム数 |
| `GESTURE_DISPLAY_MS` | 判定結果を画面に表示しておく時間 |
| `MISSING_FRAMES_TO_END` | 候補をリセットするまでの連続未検出フレーム数 |

## 使い方

センサーの正面 20〜40cm の位置でグー・チョキ・パーの手の形を作ると、画面上部に判定結果が表示されます。
